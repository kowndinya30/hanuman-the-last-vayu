# HANUMAN: THE LAST VAYU

Private pre-production repository scaffold for a premium Unreal Engine 5 cinematic action-adventure project.

## Creative promise
**Power without ego. Devotion without passivity. Myth without reduction. Spectacle with meaning.**

## Current status
Pre-production / investment-readiness. This repository is an architecture scaffold, not a certified PS5 build and not a shipping game.

## Target platforms
- PC development target
- PlayStation 5 target subject to Sony developer approval, SDK/devkit access, TRC compliance, publishing agreements and certification
- Mobile adaptation to be scoped separately rather than assumed to be a direct port

## Source-control policy
Unreal binary assets must use Git LFS. Do not commit DerivedDataCache, Intermediate, Saved, packaged builds, credentials, platform SDKs, licensed console documentation, or third-party assets without redistribution rights.
